🌤️ Sobre el proyecto

Weather es un proyecto personal de programación web creado para consultar información meteorológica de forma sencilla e interactiva.

La página utiliza la API de OpenWeatherMap para obtener los datos del tiempo.

<div align="center"> <a href="https://openweathermap.org/"> <img src="https://img.shields.io/badge/🌦️_OPENWEATHERMAP-82B3C9?style=for-the-badge&logoColor=white" alt="OpenWeatherMap"> </a> </div>
🛠️ Tecnologías
HTML5 — Estructura de la página.
CSS3 — Diseño y estilos.
JavaScript — Interactividad y conexión con la API.
OpenWeatherMap API — Obtención de datos meteorológicos.
